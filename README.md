## Instalasi

Langkah-langkah untuk menginstal:

1. Clone repo https://github.com/lutfiyadiafandi/mini-pos
2. Jalankan `npm install`
3. Pastikan copy folder public ke folder dist sebelum dijalankan
4. Jalankan `npm run dev:server` untuk menjalankan server
5. Jalankan `npm run start` untuk menjalankan electron
6. Pastikan kedua perintah diatas berjalan di terminal yang berbeda secara bersamaan
